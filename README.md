# 카카오뱅크 Kode Runner 2026 : 바이브 코딩 테트리스 (Vibe Coding Tetris)

카카오 기업 파트너 부스 방문자를 위한 고품질 아케이드 테트리스 웹 게임 프로젝트입니다.

---

## 🚀 주요 특징 (Key Features)

- **2가지 게임 모드**: 90초 부스 전용 타임어택 모드 & 레벨 가속 클래식 모드
- **카카오프렌즈 블록 고유 디자인**: 라이언, 어피치, 춘식이, 무지, 프로도, 네오, 튜브 테마
- **High-DPI Canvas 렌더링**: 60fps 부드러운 3D Arcade Gem 타일 및 파티클 효과
- **Web Audio 합성 사운드**: 동적 옥타브 피치 상승 BGM 및 아케이드 효과음
- **모바일/터치 지원**: 반응형 레이아웃 및 터치 스크린 컨트롤러

---

## 🛠️ 기술 스택 (Tech Stack)

- **Runtime & Build**: Bun, Vite
- **Language**: TypeScript
- **Graphics**: HTML5 Canvas 2D API
- **Audio**: Web Audio API Synthesis

---

## 💻 실행 및 빌드 (Getting Started)

### 의존성 설치
```bash
bun install
# 또는
npm install
```

### 개발 서버 실행
```bash
bun run dev
# 또는
npm run dev
```

### 프로덕션 빌드
```bash
bun run build
# 또는
npm run build
```
